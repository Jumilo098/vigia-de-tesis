# Repositorio de vigía de tesis

Este repositorio guarda tesis de inversión y el historial de cada revisión.

- `tesis/<nombre>/`: la idea (tesis.md), las señales (senales.md) y los tickers (watchlist.json).
- `historial/<nombre>/AAAA-MM-DD.json|md`: una foto por revisión. Nunca se borra ni se edita
  un registro viejo; si algo estaba mal, se corrige en el siguiente.
- `mi-cartera.md`: posiciones del usuario. No se sube a un repositorio público.
- Para revisar una tesis: comando `/vigia <nombre>` o la skill vigia-de-tesis.
- Cifras: copiar tal cual de Profeta. Separar "Profeta dice" de "lectura de Claude".
- Nada de esto es recomendación de inversión.
